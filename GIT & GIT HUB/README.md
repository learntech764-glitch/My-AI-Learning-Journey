Git is used to track changes in code, and GitHub is used to store, share, and collaborate on Git repositories online, making software development organized and teamwork-friendly.  

✅ Why Git is Used  

    Git is a version control system that helps developers manage changes in their code over time. It is useful because:  
        Tracks every change — You can see what changed, when, and by whom.  
        Prevents data loss — You can revert to older versions anytime.  
        Supports branching — You can experiment with new features without breaking the main project.  
        Works offline — All history is stored locally.  

✅ Why GitHub is Used  

    GitHub is a cloud platform built around Git. It adds collaboration and project management features:  
        Remote storage of your Git repositories.  
        Team collaboration through pull requests, issues, and reviews.  
        Open-source sharing — Millions of public projects to learn from.  
        Automation with GitHub Actions (CI/CD).  
        Portfolio building — Recruiters often check GitHub profiles.  

✅ Basic Git Workflow (Beginner-Friendly)  

        These are the essential commands you can include in a README:  
        # Initialize a new Git repository  
        git init  

        # Add files to staging  
        git add .  

        # Save changes with a message
        git commit -m "Initial commit"

        # Connect to a GitHub repository
        git remote add origin <repo-url>

        # Upload your code to GitHub
        git push -u origin main

✅ How GitHub Workflow Typically Works  

    Create a repository on GitHub.  
    Clone it to your computer:  
        git clone <repo-url>  
    Make changes in your local project.  
    Commit your changes.  
    Push them to GitHub.  
    For teamwork:  
        Create a branch
        Make changes
        Open a pull request
        Get your code reviewed
        Merge into main
